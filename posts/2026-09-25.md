## 本周话题

### 李笑来《自学是门手艺》

《自学是门手艺》（*The Craft of Selfteaching*）~~不是一本单纯的 Python 教材~~，而是一本==以 Python 为教具的自学方法论手册==。它的核心命题是：**没有自学能力的人没有未来**。全书用一段伪代码点题：`while not create(): learn(); practice()`，强调*学不会就继续学、继续练，直到能造出东西*；Markdown 版共 50 篇，并通过 GitHub PR 提交笔记来 *Proof-of-Work*，要求读者==用产出证明自己真的学过==。

内容结构上，开篇谈写作动机与产出证明；第一部分回答“为什么一定要自学、为什么从编程入手”，并给出极简 Python 入门，覆盖值、运算、流程控制、函数、字符串、容器、文件；第二部分聚焦函数与刻意练习，包括参数、lambda、递归、模块、TDD、可执行脚本，核心心态是*接受笨拙、耐心练习*；第三部分进入进阶主题与自学心法，如面向对象、装饰器、迭代器、生成器、正则、BNF/EBNF，以及==战胜难点、拆解问题、警惕“刚需幻觉”和注意力漂移==；收尾与附录谈沟通、学无止境、下一步，并附 VS Code、Git、JupyterLab、符号表等工具配置。

核心方法论可以压成一条主线：==从阅读官方文档开始，别怕“过早引用”，先囫囵吞枣读完==；==只学最小必要知识，然后立即动手“造”东西==；**编程是自学能力的最佳训练载体**；*接受笨拙、刻意练习、刻意思考*；==警惕以“有用”为名的收集癖和注意力漂移==；==教是最好的学，通过写作、PR、讲解来巩固==。因此，它的终点不是“学会 Python”，而是借 Python 训练一种可迁移到任何领域的自学能力：**读文档 → 抓最小必要 → 动手创造 → 刻意练习 → 输出教学 → 再学下一个**。

## 文章

- 《Chop Wood Carry Water》  - 这是一本很务实的个人成长书：反内耗、反焦虑，不催你追宏大目标，而是帮你调整时间结构、环境、原则和心态。
  * 目标不是心理安慰。日常时间花在哪里，人生才往哪里走；投入不匹配，要么改时间结构，要么改目标。
  * 圈子会塑造人。收入和能力常接近常相处朋友的平均值；身边缺少优秀的人，就用阅读、播客、讲座把欣赏的人“请”进生活。
  * 决策别总被情绪拖着走。在交朋友、不算计人、少秘密这些基本问题上形成稳定判断，纠结和内耗会少很多。
  * 目标有完成节点，使命没有。目标要服务使命，而不是反过来；否则可能爬了一辈子梯子，才发现靠错了楼。
  * 失败不是判决，是反馈。把难受时刻当成成长机会，问“哪里还能优化”，而不是“我是不是不行”。
  * 别把一切当考试。从“我能不能过关、别人怎么看我”换成“我能从中学到什么”，心态会松，做事反而更好。
  * “What Went Well”日记值得试：提醒自己价值来自我是谁，不是做了什么；写 15 条做得不错的地方和 2 个成长点。
  * 打工不是纯粹给老板干。习惯、选择、经验、人脉最终都堆回自己身上；把当前工作当成未来创业或自由职业的蓄力。
  * 书名就是核心：劈柴挑水，重复枯燥，结果不可控，过程可控。别老盯山顶，做好当下，自然会走到山顶。因上努力，果上随缘。
  ---
- 《诱惑的艺术-罗伯特·格林》 - 《诱惑的艺术》是美国作家罗伯特·格林出版的心理学与策略类著作，中文常译作《诱惑的艺术》。
  * 它不是普通恋爱指南，而是把“诱惑”视为一种影响他人、制造渴望与掌控关系的权力游戏，通过历史人物、文学角色和案例，归纳出九种诱惑者原型，如塞壬、浪子、理想情人、花花公子、魅力者等，并拆解选择对象、间接接近、制造悬念、暧昧信号、三角关系、进退节奏等策略。
  * 格林的核心观点是：吸引力的关键往往不在外貌或直接讨好，而在心理、想象力和节奏——让人得不到、猜不透、投射理想，从而产生渴望。因此，本书既被视为洞察人性的策略手册，也因鼓吹操纵、物化和性别刻板而备受争议。现实阅读时，应把它当作对权力心理的分析，而非照搬的关系指南，真正的关系仍需知情同意、尊重和边界。
  ---
- 《深入理解深度学习》 - 从基础一路讲到神经网络、CNN、Transformer、扩散模型、强化学习等核心内容，而且每章都配了 PPT + Python 练习代码，非常适合系统自学。
