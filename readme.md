# 速写本 · 样式使用指南
> 本指南以 Markdown 撰写，覆盖当前样式的全部写法。直接照抄结构，替换内容即可。
---
## 一、整体结构
每一期的 Markdown 骨架如下：
```markdown
# 第 N 期 · 本期标题
一句话开场：这周的心情、天气，或最想记下的瞬间。
## 本周话题
正文两三段。段落自动首行缩进、两端对齐，
开场第一段的第一个字会自动放大变红（首字下沉）。
## 文章
- [文章标题](https://example.com) — 一句短评：为什么值得点开
- 《某篇长文》 — 一句短评（无链接的条目也可以）
## 工具
- [工具名](https://example.com) — 一句话：干什么的 + 好在哪
## 资源
- [某个视频标题](https://example.com) — 一句短评
- 某播客单集 — 一句感受
## 新闻动态
- [某条新闻标题](https://example.com) — 一句话：这事为什么值得留意
## 言论
> 「这周读到的、听到的、或自己想到的一句。」
## 碎碎念
- 一行一条的小念头，不用成句。
- 换了新墨水，写字有沙沙的感觉。
## 本周图记
![速写 · alt 写清楚](图床URL)
```

## 二、核心：列表条目与二级内容
### 2.1 标题 + 短评条目（重点样式）
```markdown
- [文章标题](https://example.com) — 一句短评：为什么值得点开
```
**规则：**
| 部分 | 写法 | 自动获得的样式 |
|---|---|---|
| 标题 | 以 `[文字](链接)` **开头**的条目 | 墨色加粗 + 铅笔细下划线 |
| 短评 | 链接后面的 ` — 文字` | 淡灰小字，破折号自动淡化 |
**注意：**
- 破折号用 ` — `（em dash，前后有空格），保持全文一致
- 不需要任何 HTML 或特殊标记，写法正确样式自动生效
- 无链接的条目（如 `- 《某篇长文》 — 一句短评`）走普通列表样式，不做标题/短评区分
### 2.2 嵌套子列表（真正的二级内容）
```markdown
- [文章标题](https://example.com) — 一句短评
  - 补充说明：为什么收藏，或摘录一句
  - 再补一条子内容
```
**规则：**
- 子项缩进 **2 个空格**（全文统一，不要和 Tab 混用）
- 子列表自动获得：左侧虚线导轨 + 更小的菱形 + 更淡的文字
- 子列表里也可以放链接，同样会压暗处理
### 2.3 有序列表
```markdown
1. 第一点
2. 第二点
3. 第三点
```
- 编号自动显示为**中文数字**（一、二、三……），朱砂色加粗
- 有序列表下再嵌套有序列表，会退回阿拉伯数字以示区分

## 三、标题层级
```markdown
## 大板块标题
```
居中显示，两侧带双线花饰。用于「文章」「工具」等板块名。
```markdown
### 小节标题
```
行首带一个朱砂菱形。用于板块内的细分点。
```markdown
#### 更小的分组
```
行首朱砂小圆点 + 底部虚线。用于再次分组，一般少用。
> `#` 一级标题只用在期号标题上，正文内不要用。

## 四、文字强调
```markdown
这是普通段落，自动首行缩进、两端对齐。
*着重号效果*        → 文字下方出现朱砂圆点（中文点标）
**加粗效果**        → 墨色加粗
~~删除线~~          → 变灰
==荧光笔高亮==      → 黄色荧光笔划过（需渲染器支持，不支持则原样显示）
`行内代码`          → 深色底圆角小块
```
**引用**（用于「言论」板块）：
```markdown
> 「这周读到的、听到的、或自己想到的一句。」
```
自动居中，两侧配「」朱砂角标。
**分隔线**（板块之间的呼吸）：
```markdown
---
```
渲染为居中的 ❦ 花饰。

## 五、链接、图片与代码
**链接：**
```markdown
正文中的[普通链接](https://example.com) → 朱砂色，细下划线
```
**简单图片：**
```markdown
![速写 · 图片说明](https://图床地址.jpg)
```
自动居中、白边相框 + 细线描边 + 轻阴影。
**带图注的图片**（推荐用于「本周图记」）：
```markdown
<figure>
  <img src="https://图床地址.jpg" alt="图片说明">
  <figcaption>图注文字 · 例如：雨水，窗台上的绿萝</figcaption>
</figure>
```
图注自动居中、小字、前缀 ◈ 菱形。
**代码块：**
````markdown
```
代码内容
```
````
深色底、浅色字、可横向滚动。

## 六、表格
标准 Markdown 表格语法，自动获得「纸面账目风」：
```markdown
| 项目 | 说明 | 状态 |
|---|---|---|
| 表格头 | 加粗 + 粗下划线 | — |
| 数据行 | 淡墨 + 虚线分隔 | ✅ |
```
渲染效果：表头粗底线、数据行虚线分隔、悬停变米色。
---
## 七、进阶：折叠块与任务清单
**折叠块**（放长摘录、补充说明，默认收起）：
```markdown
<details>
<summary>展开看摘录</summary>
这里放长摘录或补充说明，支持 **Markdown** 语法。
</details>
```
**任务清单**（碎碎念里的待办）：
```markdown
- [ ] 未完成的事
- [x] 已完成的事
```
勾选框自动变朱砂色，条目前的小菱形自动去掉。

## 八、写法速查卡
| 我想要…… | 就这样写 |
|---|---|
| 条目 + 短评 | `- [标题](链接) — 短评` |
| 条目的二级补充 | 下一行缩进 2 空格 `- 子内容` |
| 板块标题 | `## 板块名` |
| 小节标题 | `### 小节名` |
| 引言 | `> 「句子」` |
| 着重号 | `*词语*` |
| 加粗 | `**词语**` |
| 荧光笔 | `==词语==` |
| 分隔花饰 | `---` |
| 图注 | `<figure>` + `<figcaption>` |
| 折叠块 | `<details>` + `<summary>` |
| 待办 | `- [ ] 事项` |
| 表格 | 标准 Markdown 表格 |

## 九、三条黄金规则
1. **短评统一用 ` — `**（em dash + 前后空格），全文一致，视觉才整齐。
2. **嵌套缩进统一用 2 个空格**，不要混用 Tab。
3. **链接开头的条目才有「标题 + 短评」样式**——想让某条变成重点条目，就给它套上 `[标题](链接)`；纯文字条目保持普通样式，正好用来做主次区分。
