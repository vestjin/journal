
# 速写本 · Weekly Log

一周一页：看了什么、读了什么、想到什么。不成文章，只是速写。

纯静态：一个 `index.html` 负责全部渲染，一个 `entries.txt` 列出全部期号，
每期正文是 `posts/` 下的一个 Markdown 文件。没有构建步骤，没有依赖，扔到
GitHub Pages / Cloudflare Pages / 任意静态托管即可。

---

## 目录结构

```
journal/
├── entries.txt        期号清单（每行一个日期 = posts/ 下的文件名）
├── index.html         全部逻辑：路由、Markdown 渲染、搜索、目录、定时发布
├── readme.md          本文件
└── posts/             每期正文
    ├── 2026-09-03.md
    ├── 2026-09-04.md
    └── ...
```

`entries.txt` 示例：

```
2026-09-03
2026-09-04
2026-09-11
2026-09-18
2026-09-25
```

顺序无所谓，页面加载后会按日期倒序排列（新 → 旧）。

---

## 新增一期

1. 新建 `posts/YYYY-MM-DD.md`，文件名就是那一期的日期。
2. 把日期加进 `entries.txt`。
3. 推到远端即可。

正文第一行写 `# 标题`，会作为该期标题；第一段非标题文字会截成列表页的摘要。

## 定时发布

写好了但不想立刻公开？在 Markdown 文件最前面加一段 front matter：

```md
---
publish: 2026-09-25T20:00:00+08:00
---
# 九月末

正文照常写……
```

- **到点之前**：不进目录列表、不进搜索结果、`最新` 徽章不会给它、
  `上一期 / 下一期` 导航也会跳过它。直接输入 `#/2026-09-25` 只会看到
  「这一期还没到解锁时间」。
- **到点那一刻**：如果页面正开着，会自动出现在列表里；否则刷新即可。
- **期号稳定**：期号按全量条目编号后再过滤，所以未发布那期显形时，
  「第 N 期」不会整体错位。

### `publish` 的写法

格式：`YYYY-MM-DDTHH:mm:ss±HH:mm`（ISO 8601）。

| 想表达的发布时间 | 写法 |
| --- | --- |
| 北京时间 2026-09-25 晚上 20:00 | `2026-09-25T20:00:00+08:00` |
| 北京时间 2026-09-25 早上 09:00 | `2026-09-25T09:00:00+08:00` |
| 北京时间 2026-09-25 午夜 00:00 | `2026-09-25T00:00:00+08:00` |
| 只写日期，按读者本地 00:00 解锁 | `2026-09-25` |

几点说明：

- **务必带上时区偏移** `+08:00`。不写时区（如 `2026-09-25T20:00:00`）时，
  浏览器按「读者所在时区」解析——同一个文件在不同地区解锁时间会不一样。
- 日期和时间之间用 `T`（标准写法）。写空格也能识别，脚本会自动换成 `T`。
- 时分秒可以省略（`2026-09-25T20:00` 是合法的）。
- **不写 `publish` 字段**时，按文件名日期当天 00:00 发布——也就是说，
  文件名是未来日期的帖子天然就是「未到期」的。
- 字段名写 `publish` 或 `pub` 都可以，大小写不敏感。
- 格式写错时，浏览器控制台会打印一条 `[速写本] publish 无法解析：…`，
  并回退到按文件名日期发布。

### ⚠️ 这不是权限控制

定时发布是**纯客户端隐藏**。文件此刻已经在服务器上，任何人打开 DevTools、
或直接访问 `https://你的域名/posts/2026-09-25.md`，都能拿到全文。
对「不想提前剧透」的私人速写本够用，但不算保密。

真要保密，两条路：

1. **构建期发布**：内容放在仓库另一个目录，用 GitHub Actions 的 `schedule`
   定时任务，到点跑脚本把文件 commit 进 `posts/` 并触发重新部署。
   到点前线上根本没有这个文件。零前端改动。
2. **边缘函数**：Cloudflare Worker / Netlify Edge + KV，由服务端校验时间再
   返回内容。前端不用改，但改造量最大，也是唯一真正安全的方案。

## 支持的 Markdown

手写的极简渲染器，够用就好。支持：

- 标题 `#` ~ `####`（1 级作正文内标题，页面标题另取第一行 `#`）
- 段落（首行缩进 + 两端对齐，开场段落首字下沉）
- **粗体**、`*着重号*`（渲染为中文式着重点）、`~~删除线~~`、`==荧光笔==`、`` `行内代码` ``
- 有序 / 无序列表，任意层级嵌套（嵌套的无序列表会变成虚线导轨样式；
  嵌套里的 `* 条目` 会渲染成不带项目符号的长评段）
- 任务清单 `- [x]` / `- [ ]`
- 引用 `> `（渲染为「」角标引文，居中）
- 表格（纸面账目风，支持 `:---:` 对齐）
- 代码块（``` 围栏）
- 链接、图片（点击图片放大，图床失效自动兜底提示）
- `<figure>` + `<figcaption>` 图文（图注自动加 ◈ 前缀）
- `<details>` 折叠块
- 分隔线 `---`（渲染为居中的 ❦）

## 已知取舍

- 目录侧栏只在 ≥1200px 的屏幕上显示；窄屏改用正文开头的折叠块。
- 每页 5 期，超过则出现分页。
- 图片走 `referrerpolicy="no-referrer"`，图床防盗链时也能显示。
- 搜索是纯前端子串匹配，对所有已发布期的标题、摘要、全文生效。
